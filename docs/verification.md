## Реальная конкурентность MySQL

Проверка 8 ноября: `tests/mysql-concurrency.php` запускает по два независимых PHP-процесса с отдельными соединениями InnoDB и общим сигналом старта. Фактически получено:

| Сценарий | Ответы | Инвариант |
|---|---|---|
| Два покупателя за последний остаток | 201 и 409 | один заказ, без отрицательного остатка |
| Один покупатель, один ключ | 201 и 200 | один номер заказа, одно списание |
| Одновременная отмена | 200 и 409 | каждый компонент возвращён ровно один раз |

Сервис тестируется напрямую, поэтому коды здесь соответствуют HTTP-семантике сервиса; HTTP-контроллеры отдельно проверены feature-тестами. Исходный результат: [mysql-concurrency-result.json](mysql-concurrency-result.json).

## Нагрузка каталога

Проверка 8 ноября, `tests/catalog-load.php`: отдельная база с 1000 компонентами, 20 одновременных HTTP-клиентов, 5 волн, 100 запросов. Все 100 ответов — 200; каждая страница содержит 20 строк, проверены метаданные и страницы выдачи. p95 = 1330,284 мс, максимум = 1490,330 мс. ИИ в измерения не включён. После добавления журнала нагрузочный замер не повторялся.

Это наблюдение на текущем ПК с локальным PHP-сервером. Ограничение до 2 CPU / 4 ГБ не задавалось: формальная проверка требования ТЗ на таком сервере остаётся отдельным этапом. Подробности: [catalog-load-result.json](catalog-load-result.json).

## База и документация

Миграции выполнены на MySQL. Первоначальный CourseworkSeeder создаёт 6 пользователей, 12 компонентов, 12 предложений, 6 сборок, 5 заказов и 30 позиций заказов. После текущих проверок в keycraft_demo есть дополнительные учебные записи. SQL DDL ранее экспортирован без данных/секретов и успешно импортирован в отдельную базу: 8 предметных/авторизационных таблиц, 8 внешних ключей. Пять JOIN-запросов из описания БД выполнены без ошибок.

OpenAPI 3.0.3 покрывает 39 прикладных операций без HEAD. Коллекция Postman содержит 46 запросов. Проверены JSON, ссылки схем, уникальные operationId, соответствие фактическим маршрутам, тела запросов и синтаксис скриптов Postman. Пароли/токены в коллекции пустые.

Локальный HTML /docs показывает схемы и учебные примеры без CDN. В Chrome проверены отдельный клиент, регистрация/вход/выход, каталог, CRUD сборки, совместимость, оформление заказа №6 на 60 560 ₸, конфликт остатка 409, администрирование и отмена с возвратом товара. [Браузерный протокол и снимки](client-verification.md). Это клиент из текущего репозитория; совместная приёмка с фронтендом партнёра не заявляется.

Журнал API содержит X-Request-ID, метод, путь без query, ID пользователя, статус и длительность. Пароли, email, токены, тела запросов и ключи провайдеров туда не записываются. Успех заказа и смены статуса фиксируется после commit; откат и идемпотентный повтор не добавляют ложных успешных событий. [Реальный фрагмент журнала](evidence/api-log-sample.txt).

## Для реального ИИ и сдачи

Выберите Groq или OpenAI и укажите собственный серверный ключ по [инструкции](ai.md). Ранее пользователь подтвердил работу Groq локально. В текущем прогоне внешние модели не вызывались; тесты используют Http::fake. При отсутствии ключа возвращается 503, подмены ответа модели нет.

Подготовлены записка DOCX/PDF по шаблону колледжа, девять слайдов и [сценарий защиты](defense.md). Документация остаётся локальной по выбору пользователя. Согласование темы и подписей преподавателем, совместная приёмка с фронтендом партнёра, сама защита и отправка материалов в Classroom не выполнялись.

История Git отражает реальные последовательные этапы работы, без изменения дат задним числом.
