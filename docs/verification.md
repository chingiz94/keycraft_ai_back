# Результаты проверки KeyCraft AI

Дата: 8 ноября 2026 года. Среда: Windows, PHP 8.5.1, Laravel 13.40.0, Sanctum 4.3.3, MySQL 8.4.7 / InnoDB.

## Автоматические тесты

Один и тот же набор прошёл на двух СУБД:

| Среда | Тестов | Проверок | Результат |
|---|---:|---:|---|
| SQLite в памяти | 47 | 252 | пройдено |
| Отдельная MySQL keycraft_test | 47 | 252 | пройдено |

Проверены регистрация/вход/выход/истечение токена; запрет назначения роли покупателем; права администратора и владельца; CRUD компонентов/предложений/сборок/состава; вложенные чужие позиции; удаление используемого компонента; фильтры, сортировка и пагинация; CORS; совместимость и неизвестные характеристики; актуальность суммы и цены-снимки; остатки; повторы и конфликт ключа; статусы; однократная отмена; откат после искусственной ошибки записи; повторное учебное наполнение.

В ИИ-тестах проверяются структура настоящего протокола Responses API на контролируемых HTTP-ответах, допустимые ID и количества, бюджет, совместимость, изменение наличия во время запроса, ошибки провайдера, отсутствие ключа, ограничение 10 запросов/минуту и отсутствие идентификаторов пользователя в формируемом запросе. Они не выполняют оплачиваемый вызов модели.

## Реальная конкурентность MySQL

`tests/mysql-concurrency.php` запускает по два независимых PHP-процесса с отдельными соединениями InnoDB и общим сигналом старта. Фактически получено:

| Сценарий | Ответы | Инвариант |
|---|---|---|
| Два покупателя за последний остаток | 201 и 409 | один заказ, без отрицательного остатка |
| Один покупатель, один ключ | 201 и 200 | один номер заказа, одно списание |
| Одновременная отмена | 200 и 409 | каждый компонент возвращён ровно один раз |

Сервис тестируется напрямую, поэтому коды здесь соответствуют HTTP-семантике сервиса; HTTP-контроллеры отдельно проверены feature-тестами. Исходный результат: [mysql-concurrency-result.json](mysql-concurrency-result.json).

## Нагрузка каталога

`tests/catalog-load.php`: отдельная база с 1000 компонентами, 20 одновременных HTTP-клиентов, 5 волн, 100 запросов. Все 100 ответов — 200; каждая страница содержит 20 строк, проверены метаданные и страницы выдачи. p95 = 1330,284 мс, максимум = 1490,330 мс. ИИ в измерения не включён.

Это наблюдение на текущем ПК с локальным PHP-сервером. Ограничение до 2 CPU / 4 ГБ не задавалось: формальная проверка требования ТЗ на таком сервере остаётся отдельным этапом. Подробности: [catalog-load-result.json](catalog-load-result.json).

## База и документация

Миграции выполнены на MySQL. Учебная база содержит 6 пользователей, 12 компонентов, 12 предложений, 6 сборок, 5 заказов и 30 позиций заказов. SQL DDL экспортирован без данных/секретов и успешно импортирован в отдельную базу: 8 предметных/авторизационных таблиц, 8 внешних ключей. Пять JOIN-запросов из описания БД выполнены без ошибок.

OpenAPI 3.0.3 покрывает 39 прикладных операций без HEAD. Коллекция Postman содержит 46 запросов. Проверены JSON, ссылки схем, уникальные operationId, соответствие фактическим маршрутам, тела запросов и синтаксис скриптов Postman. Пароли/токены в коллекции пустые.

В Chrome непосредственно проверены работающий `/api/v1/health` с `database: ok` и каталог с фильтрацией/пагинацией. Проверка оформления заказа через HTTP с реальным фронтендом ещё не выполнялась: фронтенд разрабатывается отдельно.

## Для реального ИИ и сдачи

Укажите свой серверный OPENAI_API_KEY, выполните рекомендацию и проверьте ответ провайдера. Реального вызова с оплачиваемым ключом в этой работе не было, заменять его имитацией приложение не пытается. При отсутствии ключа возвращается 503. Совместное тестирование с фронтендом, согласование темы/модели с преподавателем и отправка материалов в Google Classroom не выполнялись.

История Git отражает реальные последовательные этапы работы, без изменения дат задним числом.
