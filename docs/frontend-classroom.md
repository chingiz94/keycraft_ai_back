# Соответствие итоговому заданию Frontend

Исполнитель: Алимканов Жасулан, ИС-24-22б. Руководитель: Попов Д. Курс: [ИС-24-22б Основы frontend](https://classroom.google.com/c/Nzc1NDA2ODYwOTgw). Основание — [Итоговое задание 17.06–18.06.26](https://classroom.google.com/c/Nzc1NDA2ODYwOTgw/a/ODY3ODM5NzI0MTY4/details), прочитано 18.11.2026. Отчёт описывает текущую реализацию, не подтверждает оценку или приёмку преподавателем.

| Требование | Реализация и доказательство |
|---|---|
| Next.js или Nuxt | Next.js 16.4.6, App Router, TypeScript, `frontend/package-lock.json` |
| Менеджер состояния | React Context API + useReducer, `frontend/src/components/store.tsx` |
| CSS framework или UI библиотека | Tailwind CSS 4.3.5 через PostCSS, utilities для сеток, состояний и форм; собственная визуальная тема |
| Публичный сайт минимум три страницы | Главная `/`, каталог `/catalog`, описание сервиса `/guide`; общий layout и навигация |
| Форма или поиск | Живой поиск и фильтры каталога, конструктор, вход и регистрация |
| Административный SPA минимум пять разделов | Обзор, комплектующие, предложения, заказы, пользователи; маршруты `/admin/...` |
| Авторизация | Реальный Laravel Sanctum API; Guard buyer/admin и серверные проверки ролей |
| CRUD | Компоненты и предложения; личные сборки; статусы заказов и роли пользователей |
| Не менее трёх творческих элементов | GSAP появление текста/клавиш, 3D разбор по слоям, параллакс указателя, ScrollTrigger карточек; поиск без отправки формы, hover, toast, skeleton, empty/error states |
| Адаптивность | Проверены 1440×900 и 390×844, перестроение навигации, сеток и форм; таблицы прокручиваются внутри контейнера |
| Интеграция с backend | Общий HTTP-модуль, ошибки 401/422/503, токен, серверный расчёт и сохранение; готовая Laravel часть использована по разрешённому заданием варианту |
| Репозиторий и README | Содержательные коммиты в `feature/alimkanov-frontend-retail`, инструкции корня и frontend |
| Дополнительно | TypeScript, шесть модульных тестов клиента, 71 серверный тест, локальные OpenAPI/Postman |

Пояснительная записка и отчёты Frontend находятся в `docs/coursework/frontend`. Материалы Backend Нукушева Чингиза сохранены отдельно в `docs/coursework/backend`. Номера КП1–КП15 относятся к курсу Backend и не выдаются за этапы курса Frontend.

Текущий результат готов к локальной демонстрации. Публичная публикация документации Postman и сдача в Classroom не выполнялись по выбранному пользователем режиму.
