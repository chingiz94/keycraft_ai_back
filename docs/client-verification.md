# Проверка клиента КП11–КП12

Проверка выполнена 11 ноября 2026 года UTC (12 ноября по Asia/Qyzylorda), Chrome, клиент http://localhost:5173, API http://127.0.0.1:8120/api/v1. Использовалась отдельная MySQL keycraft_demo. Исходная база keycraft не очищалась. Ниже перечислены реальные действия через интерфейс.

| Действие | Наблюдение | Доказательство |
|---|---|---|
| Открыть каталог, искать и переходить по страницам | Список, фильтры, число результатов и навигация работают | [Каталог](evidence/catalog.jpg) |
| Войти buyer@keycraft.test | Клиент показывает роль покупателя и личные сборки | [Сборки](evidence/buyer-builds.jpg) |
| Открыть полную сборку 65% и проверить | compatible=true, 6 типов, сумма 6 056 000 тиынов | [Проверка](evidence/compatibility.jpg) |
| Оформить проверенную сборку | Создан заказ №6, 60 560 ₸, шесть позиций со снимками цен | [Заказ](evidence/order-created.jpg) |
| Увеличить количество свитчей до 1000 и оформить | HTTP 409: требуется 1000, доступно 799. Новый заказ не создан. Клиент показывает сообщение и X-Request-ID | [Конфликт](evidence/checkout-conflict.jpg), [журнал](evidence/api-log-sample.txt) |
| Вернуть количество 67, выйти и войти администратором | Открывается панель управления, доступны все заказы | [Администрирование](evidence/admin-catalog.jpg) |

| Открыть локальную документацию | Страница читает OpenAPI и показывает операции с примерами | [Документация](evidence/api-documentation.jpg) |

Отправка Bearer и Idempotency-Key, отсутствие cookies, обработка 401/422/204 и сетевой ошибки проверены шестью Node-тестами tests/client-api.test.mjs. Точный разрешённый origin, OPTIONS preflight и запрет постороннего origin проверены CorsTest. Реальные серверные запреты 401/403 и удаление собственной тестовой сборки проверены также Postman. Ручное окончательное удаление через браузер не выполнялось: в диалоге выбрана отмена. Отдельный снимок DevTools Network с заголовками не сделан; действующие токены в материалы не включены.

В консоли Chrome ошибок JavaScript не обнаружено. Снимки сделаны при фактической ширине области документа 836 px. Попытка установить 390 px через браузерный инструмент не изменила ширину, поэтому проверка на мобильном размере не заявляется. Для других размеров и браузеров нужна отдельная приёмка.

Браузерные и Postman-прогоны добавили учебные записи в keycraft_demo. Числа первоначального сидера описывают начальное наполнение, а не состояние базы после проверок. Сторонний фронтенд партнёра в этом протоколе не участвовал.
