## Границы проверки

- Совместимость проверяется для ANSI GMMK PRO и GMMK 2 форматов 65/75/96, MX свитчей и подтверждённого покрытия кейкапов. Ассортимент ограничен 20 моделями.
- Цены и наличие проверены 18.11.2026; это снимок, не постоянная синхронизация. За город и доставку отвечает продавец.
- reduced motion реализован и просмотрен в коде; отдельное переключение системной настройки не эмулировалось.
- Удаление покрыто feature тестами; в ручной проверке UI проверена отмена подтверждения.
- Успешный запрос Groq подтверждает доступ на момент прогона. Лимит/отказ провайдера в будущем может дать 503. Текст объяснения модели может быть неточным; итоговые цены пересчитывает сервер.
- Мобильная проверка выполнена в браузере с заданным viewport, без заявления о физических телефонах и всех движках.
- Документы подготовлены для локальной сдачи, преподавательская приёмка не выполнялась. Postman docs не публиковались.
