# Клиент KeyCraft AI

Отдельный клиент для КП11–КП12 на HTML, CSS и JavaScript. Он обращается к Laravel через fetch и не использует Blade или сборку Vite.

Из корня проекта во втором терминале:

```sh
php -S localhost:5173 -t client
```

Открыть **http://localhost:5173**. API должен работать на **http://127.0.0.1:8120**. Единая настройка API — `config.js`; в серверном `.env` должен быть `FRONTEND_URL=http://localhost:5173`. При смене адреса измените обе настройки и выполните `php artisan config:clear`.

Порт клиента обслуживает только папку `client`; API запускается отдельно. npm install для запуска этого клиента не нужен. На Windows можно запустить оба процесса командой из README проекта или через `Start-KeyCraft.ps1`.

## Страницы

| Маршрут после # | Доступ | Сценарий |
|---|---|---|
| catalog | Гость и все пользователи | Поиск, тип, формат, цена, наличие, сортировка, пагинация, карточка и предложения |
| register / login | Гость | Регистрация с подтверждением пароля и вход |
| builds | buyer | Список своих сборок и создание |
| build/ID | buyer, владелец | Название, бюджет, состав, количества, удаление с подтверждением, совместимость, оформление |
| orders / order/ID | buyer или admin | Свои либо все заказы и зафиксированные цены |
| ai | buyer | Реальный ИИ-подбор; отдельное сохранение рекомендации в сборку |
| admin/components / component/ID | admin | CRUD каталога |
| admin/offers / offer/ID | admin | CRUD предложений магазинов |
| admin/users | admin | Роли с защитой последнего администратора на сервере |
| admin/statistics | admin | Сводка заказов и выручки |

Для новой административной записи вместо ID используется `new`.

## Поведение запросов

`api.js` добавляет Accept, Content-Type и Bearer, обрабатывает JSON и ответы без тела. Токен хранится в sessionStorage текущей вкладки; при 401 удаляется и приложение показывает вход. При 422 ошибки выводятся в форме и рядом с соответствующими полями. Ошибки сети и сервера показываются явно; для серверной ошибки доступен X-Request-ID. Cookies не передаются.

Права интерфейса зависят от ответа `/auth/me`. Все ограничения дополнительно проверяет Laravel; скрытие кнопок не заменяет 403 и политики владельца.

Перед оформлением обязательна серверная проверка сборки. При сбое сети или 5xx повтор checkout использует тот же ключ и тело. После изменения состава либо ошибки 4xx нужна новая проверка; после успешного заказа ключ удаляется. Цены показываются в тенге и преобразуются в целые тиыны перед отправкой. Состав заказа и остатки определяет сервер.

ИИ использует серверный ключ провайдера. Браузер не получает этот ключ. Частично сохранённая рекомендация не теряется при сбое добавления позиции: приложение открывает созданную сборку и объясняет, что её нужно дополнить.

## Проверки

```sh
node --test tests/client-api.test.mjs
```

Команда выполняется из корня проекта и не требует установки npm-зависимостей. Протокол реального взаимодействия: `docs/client-verification.md`. Этот клиент демонстрирует серверную интеграцию по новым КП; совместная приёмка с отдельным фронтендом второго участника требует его версии проекта.
