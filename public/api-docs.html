Подключение

Базовый адрес локального API: http://127.0.0.1:8120/api/v1. JSON UTF-8. Все суммы в целых тиынах KZT: 100 тиын = 1 ₸.

Публичный каталог доступен гостю. Для защищённых маршрутов выполните регистрацию или вход и передайте Authorization: Bearer <token>. Токен Sanctum действует 24 часа. Выход отзывает текущий токен.

Каждый ответ API содержит X-Request-ID. При ошибке сохраните этот идентификатор для поиска записи в журнале. Ответы ошибок имеют поля message и errors. 401 требует входа, 403 означает отсутствие прав, 409 — конфликт бизнес-правила, 422 — ошибку данных, 429 — ограничение частоты, 503 — недоступность зависимости.

Для оформления сначала проверьте сборку, затем передайте её сумму в expected_total и уникальный Idempotency-Key. При сетевом сбое повторите одинаковый запрос с тем же ключом. Примеры ниже учебные, их ID и остатки могут отличаться от вашей базы.
